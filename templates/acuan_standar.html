Permen PUPR No. 03/PRT/M/2014
Penjelasan & Acuan

Payung hukum utama di Indonesia. Pasal 13 mewajibkan trotoar memiliki fungsi sosial (interaksi) dan ekologis (jalur hijau). Pasal 6 mengamanatkan penentuan Tingkat Pelayanan fasilitas pejalan kaki.

Implementasi pada Sistem Audit
  • Verifikasi Fungsi: Deteksi Bangku Taman (sosial) dan Pohon Peneduh (ekologis) menggunakan YOLOv11.
  • Penjaminan Kenyamanan: Keberadaan jalur hijau memadai menjaga skor tetap pada status Pemeliharaan (Skor > 90).

2. Variabel Input (Antecedent)

Variabel yang diperoleh dari hasil ekstraksi koordinat objek menggunakan algoritma YOLO:

  • Orang: Mengukur densitas pejalan kaki untuk menentukan beban pelayanan trotoar.
  • Bangku Taman: Mengukur ketersediaan sarana istirahat pejalan kaki.
  • Tempat Sampah: Mengukur dukungan kebersihan lingkungan.
  • Pohon Peneduh: Menentukan tingkat vegetasi kenyamanan termal (shade index).
  • Lampu Lalu Lintas: Indikator keamanan pada titik persimpangan.
3. Variabel Output (Consequent)

Hasil akhir sistem berupa skor numerik yang diklasifikasikan menjadi empat tingkat urgensi:

  • Pemeliharaan (🟢): Kondisi ideal, fasilitas memadai, fungsionalitas maksimal.
  • Perencanaan (⚪): Kondisi stabil, namun memerlukan rencana pengembangan kapasitas.
  • Monitoring (🟡): Kondisi kenyamanan mulai berkurang, memerlukan pengawasan rutin.
  • Intervensi (🟠): Kondisi kritis, fasilitas nol di area ramai, butuh perbaikan segera.

6. Rule Base (12 Aturan Utama - Fokus Fasilitas)

Logika memprioritaskan kualitas infrastruktur fisik sebagai penahan skor utama.

  1. IF (pohonpeneduh is memadai) THEN (urgensi is Pemeliharaan)
  2. IF (bangkutaman is memadai) THEN (urgensi is Pemeliharaan)
  3. IF (tempatsampah is memadai) THEN (urgensi is Pemeliharaan)
  4. IF (orang is sepi) THEN (urgensi is Pemeliharaan)
  5. IF (bangkutaman is memadai) AND (pohonpeneduh is memadai) THEN (urgensi is Pemeliharaan)
  6. IF (lampulalulintas is ada) THEN (urgensi is Pemeliharaan)
  7. IF (pohonpeneduh is minim) THEN (urgensi is Perencanaan)
  8. IF (bangkutaman is minim) THEN (urgensi is Perencanaan)
  9. IF (bangkutaman is minim) AND (pohonpeneduh is minim) THEN (urgensi is Monitoring)
  10. IF (orang is ramai) AND (pohonpeneduh is memadai) THEN (urgensi is Pemeliharaan)
  11. IF (orang is ramai) AND (bangkutaman is memadai) THEN (urgensi is Pemeliharaan)
  12. IF (orang is ramai) AND (bangkutaman is minim) AND (pohonpeneduh is minim) THEN (urgensi is Intervensi)
